📘 Decimal Guide

Use this anytime. It does not cost points.

➕ ADDITION

1. Line up the decimal points.
2. Add zeros if needed so place values match.
3. Add from right to left.
4. Bring the decimal straight down into the answer.
 7.50
+2.36
─────
➖ SUBTRACTION

1. Line up the decimal points.
2. Add zeros if needed.
3. Subtract from right to left.
4. Regroup when needed.
5. Bring the decimal straight down.
 8.50
−3.27
─────
✖ MULTIPLICATION

1. Ignore the decimals first.
2. Multiply like whole numbers.
3. Count the decimal places in both factors.
4. Add those counts together.
5. Move the decimal in the product that many places from the right.
Remember:
decimal places + decimal places
= places in the product
➗ DIVISION

1. Look at the divisor first.
2. Move its decimal right until the divisor is a whole number.
3. Move the dividend decimal the same number of places.
4. Add zeros if needed.
5. Divide normally.
6. Bring the decimal straight up into the quotient.
Remember:
Whatever you do to the divisor's decimal, do the same to the dividend.
