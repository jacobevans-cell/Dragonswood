DRAGONSWOOD v42 — DETAILED LEADERBOARD + SEPARATE PASSES TAB

LEADERBOARD
• Student leaderboard now shows more than a mystery number.
• New records can display game, activity, subject, lesson, session, score type, accuracy,
  correct/total, day, and date.
• Filters: ALL / MATH / ELA / DAILY QUEST / OTHER GAMES.
• Daily Quest now saves rich score metadata for all NEW leaderboard records:
  Morning Bell Work or Exit Quest, Math + ELA, both skill names, score type, accuracy,
  correct/attempts, day, and date.
• Old records are preserved. They can only display metadata that was originally saved.

TEACHER PASSES
• New PASSES tab separates pass management from the Students tab.
• Pass Blackout, Bathroom live/history/requests, Snack live/history/requests,
  and Out of Seat/Office live/history are together.
• Recognition requests remain on Students.

TEACHER LEADERBOARD
• Leaderboard Manager now shows available activity, subject, lesson/session,
  accuracy, correct/total, and date information.

FIRESTORE
• No new rule change beyond v41 is required.
• The current firestore.rules remains included.
