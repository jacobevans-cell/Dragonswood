DRAGONSWOOD v48 — DAILY QUEST ENGAGEMENT + RESET

BASE
- Built directly from Dragonswood v47 three-track Daily Quest.

DAILY QUEST
- 4th Grade, 5th Grade, and ⭐ Challenge tracks remain.
- Student landing page now clearly displays YOUR DAILY QUEST LEVEL.
- Teacher can see each student's Quest Track in the Student Roster.
- Change a student's level at:
  Teacher Portal > Students > Student Roster > Manage > Daily Quest Track.
- Auto by Grade uses the student's saved grade.
- Challenge is teacher-assigned and capped at early–mid 6th-grade enrichment.

RESET

- Everyone starts the Daily Quest fresh after deployment.
- Old RPG reward claims are NOT erased, so replaying reset work does not duplicate XP/Gold rewards.

QUESTION QUALITY

- Crystal Hunt now uses real academic answer choices.
- Potion / ingredient drag-and-drop remains.

SUPPORT

- Read Aloud remains available.
- Language selector appears ONLY on ⭐ Challenge Word of the Day.
- Ordinary 4th/5th questions no longer show a language selector.

TIMING

- Exit Quest: target 15–20 minutes.

FIREBASE
