DRAGONSWOOD v48.2 — OPEN RESPONSE VOCABULARY ANSWER BANK

Built on v48.1 Visual Coach Fix.

- Added a large local synonym/antonym accepted-answer bank.
- Rune Lock typed ELA responses now normalize capitalization, punctuation, quotes, and extra spaces.
- Word-relationship questions accept multiple legitimate answers instead of one hidden exact string.
- Example: antonyms for ANCIENT accept modern, new, recent, current, contemporary, and newest.
- The bank is deliberately curated rather than accepting every thesaurus near-antonym, because context matters.
- No live dictionary API is called during student play, so this adds no Firebase reads and does not depend on an outside service.
